# NN - Object Bunkai Tool

VRChatアバターや衣装、小物などのメッシュを分解・統合するUnity Editorツールです。

## VCC / VPM

Package ID: `com.nekoneko.object-bunkai-tool`

VPM Repository URL:

`https://raw.githubusercontent.com/kureh4/NN-Object-Bunkai-Tool/main/Website/index.json`

VCCの **Settings > Packages > Add Repository** から上記URLを追加すると、
Manage Projectから **NN - Object Bunkai Tool** を導入・更新できます。

## Generated

ツール本体はVPMでは `Packages/com.nekoneko.object-bunkai-tool/` に導入されます。

生成したPrefab / Mesh / Materialは従来どおり
`Assets/nekoneko/NN - Object Bunkai Tool/Generated/`
へ保存されます。
